# Escape The Hell

## Description
- Escape the hell is a 2d platformer game built in Unity. The player is trapped in the underworld hell surrounded by lava, rocks, mysterious beings and dangerous objects, the player must move out from the hell and reach the top to get to the heaven. The player can move by using their mouse to drag and launch the player to the opposite direction they dragged.
(This game was my first game that I had ever built, and now I have upgraded it completely. If you are wondering why there was no readme previously,  I was so begineer at game development that I watched tutorial on multiple how to build X mechanics. )

## Game Mechanics
- PlayerMovement is based on mouse dragging(slingshot)
- There are two modes on aiming:
 - Normal Mode
 - Tragectory Mode (Hold ctrl while dragging to activate this mode)
- Multiple hazards can kill you instantly
- Multiple Checkpoints are kept to make the game a bit easier
- You will learn the game mechanics while you continue playing the game

## Goal
- To escape the hell and reach heaven

- LeftMousebtn Dragging
